Ao longo da minha carreira, desenvolvi um conjunto de habilidades diversificado e robusto em múltiplas linguagens de programação, o que me permitiu enfrentar uma ampla gama de desafios de desenvolvimento. Aqui está um olhar sobre minha jornada e as linguagens que dominei ao longo do caminho.

#### Java

Java foi uma parte fundamental da minha educação formal em ciência da computação. Aprender Java durante meus estudos universitários me ensinou os princípios da programação orientada a objetos e me deu as habilidades para desenvolver aplicações robustas e escaláveis. Usei Java em vários contextos, desde a construção de aplicações corporativas até o desenvolvimento de apps Android.

#### HTML

Minha jornada no desenvolvimento web começou com HTML, a pedra angular das páginas web. Aprender HTML me deu uma compreensão fundamental de como os sites são estruturados, permitindo-me criar conteúdo web bem organizado e semanticamente rico. Esta experiência inicial estabeleceu a base para tudo que se seguiu.

#### CSS

Para complementar minhas habilidades em HTML, mergulhei no CSS. Dominar CSS me permitiu estilizar páginas web com precisão, dando vida aos meus designs com layouts envolventes e elementos visualmente atraentes. Este conhecimento foi crucial para criar sites amigáveis ao usuário e esteticamente agradáveis.

#### JavaScript

JavaScript foi um divisor de águas na minha jornada de programação. Ele me permitiu adicionar interatividade e comportamento dinâmico às páginas web, tornando-as mais envolventes e funcionais. Aprimorei minhas habilidades em JavaScript através de vários projetos, aprendendo a manipular o DOM, lidar com eventos e criar aplicações complexas.

#### TypeScript

Para aprimorar ainda mais minhas habilidades em JavaScript, adotei o TypeScript. Esta linguagem poderosa me introduziu à tipagem estática, que melhorou a confiabilidade e manutenibilidade do meu código. TypeScript tem sido inestimável na construção de aplicações de grande escala com maior facilidade e confiança.

#### Python

Meu interesse no desenvolvimento backend me levou ao Python. Sua simplicidade e legibilidade o tornam uma excelente escolha para programação do lado do servidor. Usei Python para construir aplicações web, automatizar tarefas e analisar dados, apreciando sua versatilidade e forte suporte da comunidade.

#### C++

Para entender alguns dos conceitos abstraídos nas linguagens de programação modernas, estudei C++ através da certificação "Programming in C++: A Hands-on Introduction Specialization". Esta experiência aprofundou minha compreensão de conceitos de programação de baixo nível, como gerenciamento de memória, ponteiros e otimização de desempenho, que são habilidades essenciais para programação de sistemas e desenvolvimento de jogos.

### Meta Certified Back-End Developer

Para solidificar minha expertise em desenvolvimento backend, busquei e alcancei a Certificação Meta Back-End Developer. Esta certificação validou minhas habilidades e conhecimento na construção de sistemas backend eficientes, escaláveis e seguros. Foi um marco significativo que aumentou minha credibilidade e abriu novas oportunidades na indústria.

### Conclusão

Cada linguagem que aprendi contribuiu de forma única para minha expertise em desenvolvimento, equipando-me com as habilidades necessárias para construir soluções abrangentes e eficientes. Seja trabalhando em designs frontend, sistemas backend ou aplicações full-stack, minha proficiência diversificada em linguagens me permite adaptar e exceler em vários ambientes de programação.
