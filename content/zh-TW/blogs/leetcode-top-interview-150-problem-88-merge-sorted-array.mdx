歡迎來到另一個程式設計之旅！今天，我們將深入探討 LeetCode 上經常遇到的熱門面試問題：**合併排序陣列**。這個任務看似簡單卻很有技巧性；將兩個排序陣列合併成一個排序陣列。這個挑戰在處理邊界情況和確保最佳效率時經常讓人措手不及。

以下是問題陳述的簡要摘要：

給定兩個整數陣列 `nums1` 和 `nums2`，按非遞減順序排序，以及兩個整數 `m` 和 `n`，分別表示 `nums1` 和 `nums2` 中的元素數量，將 `nums2` 合併到 `nums1` 中，使 `nums1` 成為一個排序陣列。

### 初始設定

這裡的技巧是利用 `nums1` 在末尾有足夠空間來容納 `nums2` 所有元素的事實（如問題所指定）。我們將從末尾開始向前合併陣列，以避免覆蓋 `nums1` 中尚未處理的元素。

以下是提供的程式碼片段：


```cpp
class Solution {
public:
    void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
        int i = m - 1;
        int j = n - 1;
        int k = m + n - 1;

        while (j >= 0) {
            if (i >= 0 && nums1[i] > nums2[j]) {
                nums1[k--] = nums1[i--];
            } else {
                nums1[k--] = nums2[j--];
            }
        }
    }
};
```

### 程式碼解釋

- **變數初始化**：

- `i` 從 `nums1` 的最後一個有效元素開始。

- `j` 從 `nums2` 的最後一個元素開始。

- `k` 從陣列 `nums1` 中放置合併陣列最終元素的最後位置開始。

- **合併過程**：

- `while` 迴圈持續進行，直到 `nums2` 的所有元素都被考慮（即 `j >= 0`）。

- 在迴圈內部，我們從末尾到開頭比較 `nums1` 和 `nums2` 的元素。

- 如果 `nums1` 的當前元素（`nums1[i]`）大於 `nums2` 的當前元素（`nums2[j]`），我們將 `nums1[i]` 放在 `nums1` 的位置 `k`，並同時減少 `i` 和 `k`。

- 否則，我們將 `nums2[j]` 放在位置 `k`，並同時減少 `j` 和 `k`。

### 為什麼從末尾合併？

從末尾合併是一個策略性的選擇，因為它允許我們從後面填充 `nums1`，避免了移動元素來騰出空間的需要。這種技術確保合併操作是高效的，時間複雜度為 O(m + n)，其中 m 和 n 是兩個陣列的長度。

### 結論

這個解決方案在簡潔性和效率方面都很優雅。它利用了 `nums1` 內提供的空間，確保不需要額外的空間，符合原地合併的約束條件。
