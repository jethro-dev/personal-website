在我的職業生涯中，我掌握了多種程式語言，建構了多元而扎實的技能體系，這使我能夠應對各種各樣的開發挑戰。讓我帶你回顧我的成長歷程，以及一路走來所精通的程式語言。

#### Java

Java 是我電腦科學正規教育中的重要組成部分。在大學期間學習 Java，讓我深入理解了物件導向程式設計的原理，並賦予了我開發健壯且可擴展應用程式的能力。從建構企業級應用到開發 Android 應用，我在各種場景中都運用過 Java。

#### HTML

我的 Web 開發之旅始於 HTML——網頁的基石。學習 HTML 讓我對網站的結構有了基礎性的理解，使我能夠創建結構良好、語義豐富的網頁內容。這段早期的經歷為後續的一切奠定了基礎。

#### CSS

為了完善我的 HTML 技能，我深入研究了 CSS。精通 CSS 使我能夠精確地為網頁添加樣式，透過引人入勝的佈局和視覺上吸引人的元素讓設計栩栩如生。這些知識對於創建使用者友好且美觀的網站至關重要。

#### JavaScript

JavaScript 是我程式設計旅程中的轉捩點。它讓我能夠為網頁添加互動性和動態行為，使它們更具吸引力和功能性。透過各種專案，我磨練了 JavaScript 技能，學會了操作 DOM、處理事件以及創建複雜的應用程式。

#### TypeScript

為了進一步提升我的 JavaScript 技能，我開始使用 TypeScript。這門強大的語言讓我接觸到了靜態型別，提高了程式碼的可靠性和可維護性。在建構大型應用程式時，TypeScript 讓我更加輕鬆自信。

#### Python

對後端開發的興趣引領我走向了 Python。它的簡潔性和可讀性使其成為伺服器端程式設計的絕佳選擇。我用 Python 建構過 Web 應用、自動化任務和資料分析，深深欣賞它的多功能性和強大的社群支援。

#### C++

為了理解現代程式語言中被抽象化的一些概念，我透過「C++ 程式設計：實務入門專項課程」認證學習了 C++。這段經歷加深了我對底層程式設計概念的理解，如記憶體管理、指標和效能最佳化，這些都是系統程式設計和遊戲開發的必備技能。

### Meta 認證後端開發者

為了鞏固我在後端開發方面的專業能力，我努力獲得了 Meta 後端開發者認證。這項認證驗證了我在建構高效、可擴展和安全後端系統方面的技能和知識。這是一個重要的里程碑，提升了我的專業信譽，也為我在業界開啟了新的機遇。

### 結語

我學習的每一門語言都為我的開發專長做出了獨特的貢獻，讓我具備了建構全面而高效解決方案所需的技能。無論是前端設計、後端系統，還是全端應用，我多樣化的語言能力讓我能夠在各種程式設計環境中適應並脫穎而出。
