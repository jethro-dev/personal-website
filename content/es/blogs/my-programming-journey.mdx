A lo largo de mi carrera, he desarrollado un conjunto de habilidades diverso y sólido en múltiples lenguajes de programación, lo que me ha permitido abordar una amplia gama de desafíos de desarrollo. Este es un vistazo a mi viaje y los lenguajes que he dominado en el camino.

#### Java

Java fue una parte clave de mi educación formal en ciencias de la computación. Aprender Java durante mis estudios universitarios me enseñó los principios de la programación orientada a objetos y me dio las habilidades para desarrollar aplicaciones robustas y escalables. He usado Java en varios contextos, desde la construcción de aplicaciones de nivel empresarial hasta el desarrollo de aplicaciones Android.

#### HTML

Mi viaje hacia el desarrollo web comenzó con HTML, la piedra angular de las páginas web. Aprender HTML me dio una comprensión fundamental de cómo se estructuran los sitios web, permitiéndome crear contenido web bien organizado y semánticamente rico. Esta experiencia temprana sentó las bases para todo lo que siguió.

#### CSS

Para complementar mis habilidades en HTML, me sumergí en CSS. Dominar CSS me permitió dar estilo a las páginas web con precisión, dando vida a mis diseños con diseños atractivos y elementos visualmente llamativos. Este conocimiento fue crucial para crear sitios web fáciles de usar y estéticamente agradables.

#### JavaScript

JavaScript fue un punto de inflexión en mi viaje de programación. Me permitió agregar interactividad y comportamiento dinámico a las páginas web, haciéndolas más atractivas y funcionales. Perfeccioné mis habilidades en JavaScript a través de varios proyectos, aprendiendo a manipular el DOM, manejar eventos y crear aplicaciones complejas.

#### TypeScript

Para mejorar aún más mis habilidades en JavaScript, adopté TypeScript. Este poderoso lenguaje me introdujo al tipado estático, lo que mejoró la confiabilidad y mantenibilidad de mi código. TypeScript ha sido invaluable para construir aplicaciones a gran escala con mayor facilidad y confianza.

#### Python

Mi interés en el desarrollo backend me llevó a Python. Su simplicidad y legibilidad lo convierten en una excelente opción para la programación del lado del servidor. He usado Python para construir aplicaciones web, automatizar tareas y analizar datos, apreciando su versatilidad y fuerte soporte de la comunidad.

#### C++

Para entender algunos de los conceptos abstraídos en los lenguajes de programación modernos, estudié C++ a través de la Certificación "Programming in C++: A Hands-on Introduction Specialization". Esta experiencia profundizó mi comprensión de conceptos de programación de bajo nivel como gestión de memoria, punteros y optimización de rendimiento, que son habilidades esenciales para la programación de sistemas y desarrollo de juegos.

### Desarrollador Backend Certificado por Meta

Para solidificar mi experiencia en desarrollo backend, busqué y logré la Certificación de Desarrollador Backend de Meta. Esta certificación validó mis habilidades y conocimientos en la construcción de sistemas backend eficientes, escalables y seguros. Fue un hito significativo que mejoró mi credibilidad y abrió nuevas oportunidades en la industria.

### Conclusión

Cada lenguaje que he aprendido ha contribuido de manera única a mi experiencia en desarrollo, equipándome with las habilidades necesarias para construir soluciones integrales y eficientes. Ya sea trabajando en diseños frontend, sistemas backend o aplicaciones full-stack, mi competencia diversa en lenguajes me permite adaptarme y destacar en varios entornos de programación.
