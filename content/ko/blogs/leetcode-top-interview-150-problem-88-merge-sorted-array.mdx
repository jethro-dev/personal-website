또 다른 코딩 여정에 오신 것을 환영합니다! 오늘은 LeetCode에서 자주 마주치는 인기 있는 면접 질문인 **정렬된 배열 병합**에 대해 알아보겠습니다. 과제는 간단하지만 까다롭습니다. 두 개의 정렬된 배열을 하나의 정렬된 배열로 병합하는 것입니다. 이 도전은 종종 엣지 케이스 처리와 최적 효율성 보장에 있어서 사람들을 당황하게 만듭니다.

문제 설명을 간단히 요약하면 다음과 같습니다:

비내림차순으로 정렬된 두 정수 배열 `nums1`과 `nums2`, 그리고 각각 `nums1`과 `nums2`의 원소 개수를 나타내는 두 정수 `m`과 `n`이 주어졌을 때, `nums2`를 `nums1`에 병합하여 `nums1`을 하나의 정렬된 배열로 만드세요.

### 초기 설정

여기서 핵심은 `nums1`이 `nums2`의 모든 원소를 수용할 수 있을 만큼 끝부분에 충분한 공간이 있다는 사실을 활용하는 것입니다(문제에서 명시됨). 아직 처리되지 않은 `nums1`의 원소들을 덮어쓰지 않기 위해 배열을 끝에서부터 시작하여 병합할 것입니다.

제공된 코드 스니펫은 다음과 같습니다:

```cpp
class Solution {
public:
    void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
        int i = m - 1;
        int j = n - 1;
        int k = m + n - 1;

        while (j >= 0) {
            if (i >= 0 && nums1[i] > nums2[j]) {
                nums1[k--] = nums1[i--];
            } else {
                nums1[k--] = nums2[j--];
            }
        }
    }
};
```

### 코드 설명

- **변수 초기화**:

- `i`는 `nums1`의 마지막 유효한 원소에서 시작합니다.

- `j`는 `nums2`의 마지막 원소에서 시작합니다.

- `k`는 병합된 배열의 최종 원소가 배치될 `nums1` 배열의 마지막 위치에서 시작합니다.

- **병합 과정**:

- `while` 루프는 `nums2`의 모든 원소가 고려될 때까지 계속됩니다(즉, `j >= 0`).

- 루프 내에서 `nums1`과 `nums2`의 원소들을 끝에서부터 시작하여 비교합니다.

- `nums1`의 현재 원소(`nums1[i]`)가 `nums2`의 현재 원소(`nums2[j]`)보다 크면, `nums1[i]`를 `nums1`의 `k` 위치에 배치하고 `i`와 `k`를 모두 감소시킵니다.

- 그렇지 않으면 `nums2[j]`를 `k` 위치에 배치하고 `j`와 `k`를 모두 감소시킵니다.

### 왜 끝에서부터 병합하는가?

끝에서부터 병합하는 것은 전략적인 선택입니다. 이렇게 하면 뒤에서부터 `nums1`을 채울 수 있어서 공간을 만들기 위해 원소들을 이동시킬 필요가 없습니다. 이 기법은 병합 작업이 효율적이도록 보장하며, 시간 복잡도는 O(m + n)입니다. 여기서 m과 n은 두 배열의 길이입니다.

### 결론

이 해법은 단순함과 효율성에서 우아합니다. `nums1` 내에서 제공된 공간을 활용하여 추가 공간이 필요하지 않도록 보장하며, 제자리 병합의 제약 조건을 준수합니다.
