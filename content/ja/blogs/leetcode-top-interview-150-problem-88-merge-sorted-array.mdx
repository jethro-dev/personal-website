コーディングの旅の新たな章へようこそ！本日は、LeetCodeで頻繁に遭遇する人気の面接問題である**ソート済み配列のマージ**に取り組みます。タスクはシンプルですがトリッキーです。2つのソート済み配列を1つのソート済み配列にマージします。この問題は、エッジケースの処理と最適な効率性の確保において、しばしば人々を困惑させます。

問題文の要約は以下の通りです：

非降順にソートされた2つの整数配列`nums1`と`nums2`、および`nums1`と`nums2`のそれぞれの要素数を表す2つの整数`m`と`n`が与えられます。`nums2`を`nums1`にマージして、`nums1`を単一のソート済み配列にしてください。

### 初期設定

ここでのトリックは、`nums1`の末尾に`nums2`のすべての要素を収容するのに十分なスペースがあるという事実を活用することです（問題の指定通り）。`nums1`でまだ処理されていない要素を上書きすることを避けるため、配列を末尾から始まりに向かってマージします。

以下が提供されたコードスニペットです：

```cpp
class Solution {
public:
    void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
        int i = m - 1;
        int j = n - 1;
        int k = m + n - 1;

        while (j >= 0) {
            if (i >= 0 && nums1[i] > nums2[j]) {
                nums1[k--] = nums1[i--];
            } else {
                nums1[k--] = nums2[j--];
            }
        }
    }
};
```

### コードの説明

- **変数の初期化**：

- `i`は`nums1`の最後の有効な要素から開始します。

- `j`は`nums2`の最後の要素から開始します。

- `k`は、マージされた配列の最終要素が配置される`nums1`の最後の位置から開始します。

- **マージプロセス**：

- `while`ループは、`nums2`のすべての要素が考慮されるまで続きます（つまり、`j >= 0`）。

- ループ内では、`nums1`と`nums2`の要素を末尾から始まりに向かって比較します。

- `nums1`の現在の要素（`nums1[i]`）が`nums2`の現在の要素（`nums2[j]`）より大きい場合、`nums1[i]`を`nums1`の位置`k`に配置し、`i`と`k`の両方を減らします。

- そうでなければ、`nums2[j]`を位置`k`に配置し、`j`と`k`の両方を減らします。

### なぜ末尾からマージするのか？

末尾からマージするのは戦略的な動きです。これにより、`nums1`を後ろから埋めることができ、スペースを作るために要素をシフトする必要がなくなります。この技術により、マージ操作が効率的になり、時間計算量がO(m + n)となります。ここで、mとnは2つの配列の長さです。

### まとめ

この解法は、そのシンプルさと効率性において優雅です。`nums1`内の提供されたスペースを活用し、追加のスペースが不要であることを保証し、インプレースマージの制約に準拠しています。
