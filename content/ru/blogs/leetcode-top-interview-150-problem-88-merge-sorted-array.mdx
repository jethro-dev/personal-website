Добро пожаловать в очередное путешествие по программированию! Сегодня мы погружаемся в популярный вопрос для интервью, часто встречающийся на LeetCode: **Слияние Отсортированных Массивов**. Задача проста, но хитра; объединить два отсортированных массива в один отсортированный массив. Вызов часто застает людей врасплох, когда дело доходит до обработки граничных случаев и обеспечения оптимальной эффективности.

Вот краткое изложение постановки задачи:

Даны два массива целых чисел `nums1` и `nums2`, отсортированные в неубывающем порядке, и два целых числа `m` и `n`, представляющие количество элементов в `nums1` и `nums2` соответственно, объедините `nums2` в `nums1`, делая `nums1` единым отсортированным массивом.

### Начальная Настройка

Хитрость здесь в том, чтобы использовать тот факт, что в `nums1` есть достаточно места в конце для размещения всех элементов из `nums2` (как указано в задаче). Мы будем объединять массивы с конца к началу, чтобы избежать перезаписи элементов в `nums1`, которые еще не были обработаны.

Вот предоставленный фрагмент кода:

```cpp
class Solution {
public:
    void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
        int i = m - 1;
        int j = n - 1;
        int k = m + n - 1;

        while (j >= 0) {
            if (i >= 0 && nums1[i] > nums2[j]) {
                nums1[k--] = nums1[i--];
            } else {
                nums1[k--] = nums2[j--];
            }
        }
    }
};
```

### Объяснение Кода

- **Инициализация Переменных**:

- `i` начинается с последнего валидного элемента `nums1`.

- `j` начинается с последнего элемента `nums2`.

- `k` начинается с последней позиции в массиве `nums1`, где будет размещен финальный элемент объединенного массива.

- **Процесс Слияния**:

- Цикл `while` продолжается, пока все элементы `nums2` не будут рассмотрены (т.е., `j >= 0`).

- Внутри цикла мы сравниваем элементы из `nums1` и `nums2` с конца к началу.

- Если текущий элемент `nums1` (`nums1[i]`) больше, чем текущий элемент `nums2` (`nums2[j]`), мы помещаем `nums1[i]` в позицию `k` в `nums1` и уменьшаем и `i`, и `k`.

- В противном случае мы помещаем `nums2[j]` в позицию `k` и уменьшаем и `j`, и `k`.

### Почему Слияние с Конца?

Слияние с конца – это стратегический ход, потому что это позволяет нам заполнять `nums1` сзади, избегая необходимости сдвигать элементы для освобождения места. Эта техника обеспечивает эффективность операции слияния со временной сложностью O(m + n), где m и n – длины двух массивов.
